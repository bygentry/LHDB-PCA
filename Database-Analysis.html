An Investigation of Primate Life History Data Quality

Author

Gentry Miller

Introduction

“Given this general importance of life history data and with the scientific ideals of transparency and repeatability in mind, one would assume that researchers have long since agreed upon life history definitions and are using reliable and accurate data stored in standardized repositories. However, while various databases exist, standards for data quality and specification are lacking.” (Borries et al. 2013)

Life history theory has provided not just a framework to understand how organisms maximize fitness, but a lexicon of variables that represent a shared currency across organisms. Key variables have emerged to characterize growth (weaning age ), reproduction (age at sexual maturity, first reproduction), and duration of reproduction (lifespan). Despite the widespread use of such measures, researchers face consistent methodological challenges in collating life history data for comparative analyses including access to a substantial range, differences in definitions, discrepancies in data quality, and decision trees on which variables to use and how. 

Here we present a guide that addresses these and other issues for primatologists who want to employ life history data. We review the characteristics of five databases that contain life history data on primates. We also present a frequently advocated approach to summarize variation across traits using dimension reduction analysis, with which we summarize data here.

Filtering Primate Data

Four of the databases under investigation include data for more animals than primates - pulling out the primate data makes analysis cleaner and easier.

Missing Values and Point Correction

Our .csv of the Kappeler & Pereira database was transcribed by hand from a digital scan of the original paper publication. One value of adult female body mass (BM.F) in the Kappeler & Pereira data has a “?”, making the object type ‘character’ instead of ‘numeric’ . Mixing number and non-number characters will result in forced NA for that value when converting to type numeric, so the ‘?’ is removed to include the value in completeness tests. Additionally, several of the databases use -999 as the “missing value” - these are converted to NA for all fields of type numeric to allow quantitative analysis.

Standardizing Units

To make valid comparisons, variables across databases should be in common units. There are several changes to be made to standardize the units to meet these conditions:

  1. Longevity is reported in years

  2. All other time values are reported in days

  3. All mass values are reported in grams

Some of the time values are reported in months - I treat a month as the average length of a month in the Gregorian calendar in days and use these conversion factors throughout unit standardization:

\[ 1 \text{ year } = \frac{365.25 \text{ days}}{1 \text{ year}} = \frac{365.25 \text{ days}}{12 \text{ months}} \approx \frac{30.44 \text{ days}}{1 \text{ month}} \\ \]

The following unit changes are necessary:

Amniotes (Myrhvold et al. 2015):

  • Inter-birth Interval (IBI) should be converted from years to days

AnAge (de Magalhães & Costa 2009):

  • No changes necessary

Ernest (2003):

  • Age at First Reproduction (AFR), Gestation Length (gest_len), and Weaning Age (weaning_age) should be converted from months to days

  • IBI should be converted from litters/year to days

    • IBI is effectively days/birth (or days/litter) and can be derived from litters/year as such:

      \[ 1 \, \div \frac{x \text{ litters}}{1 \text{ year}} = \frac{x \text{ years}}{1 \text{ litter}} \,\times \, \frac{365.25 \text{ days}}{1 \text{ year}} = \frac{x \text{ days}}{1\text{ litter}} \]

  • Maximum Longevity (max_longevity) should be converted from months to years

PanTHERIA (Jones et al. 2009):

  • Maximum Longevity should be converted from months to years

Kappeler & Pereira (2003):

  • IBI should be converted from months to days
Code 
days_per_year <- 365.25
months_per_year <- 12
days_per_month <- days_per_year/months_per_year

amniote_s <- amniote_s %>% 
  mutate(
    IBI = IBI * days_per_year
    # converts years to days
  )

ernest_s <- ernest_s %>% 
  mutate(
    AFR = AFR * days_per_month,
    # converts months to days
    gest_len = gest_len * days_per_month,
    # converts months to days
    IBI = days_per_year/IBI,
    # converts litters/year to IBI (days)

## combine values from key value dfs of each source into a single df "key_vals"
key_vals <- bind_rows(amniote_s, AnAge_s, ernest_s, kp_s, pan_s)

## this calculates the proportion of missing values for each life history trait
## and stores them in a "missigness" df that stores the trait, the source, 
## and the % missingness in 3 steps
## (1) pivots columns except for species and source, 
##     assigns variable names to trait and values to value 
## (2) groups traits sourcewise
## (3) calculates the proportion of NAs to valid entries for each trait
##     in each source and stores them alongside the source and trait name
missingness <- key_vals %>%
  pivot_longer(cols = -c(species, source), 
               names_to = "trait", 
               values_to = "value") %>%
  group_by(source, trait) %>% 
  summarize(prop_missing = mean(is.na(value)), .groups = "drop")

missingness_no_sex <- key_vals %>%

               names_to = "trait", 
               values_to = "value") %>%
  group_by(source, trait) %>%

## makes a new df using prop_missing values from 
## missingness df and averages them by source, then stores
## in new df mean_missing
mean_missing <- missingness %>% 
  group_by(source) %>% 
  summarise(
    mean_missingness = mean(prop_missing)
    )

## takes the inverse proportion of the mean missingness
## for each database to give mean completeness
mean_complete <- mean_missing %>% 
  mutate(mean_completeness = 1 - mean_missingness)

## removing sexed variables
mean_missing_no_sex <- missingness_no_sex %>% 
  group_by(source) %>% 
  summarise(
    mean_missingness_no_sex = mean(prop_missing)
  )

## takes the inverse proportion of the mean missingness
## for each database to give mean completeness
mean_complete_no_sex <- mean_missing_no_sex %>% 
  mutate(mean_completeness_no_sex = 1 - mean_missingness_no_sex)

composite_completeness <- mean_complete %>% 
  inner_join(mean_complete_no_sex, by = "source") %>% 
  mutate(
    cap = pmax(0, mean_completeness_no_sex - mean_completeness)
  )

# create list of sex dependent variable names for checking sex dependency
sex_dep_vars <- c("Sexual Maturity - Female (Days)", "Sexual Maturity - Male (Days)", "Sexual Maturity - Unspecified (Days)", "Adult Mass - Female (g)", "Adult Mass - Male (g)", "Adult Mass - Unspecified (g)")

# create a new df for the permutation test
## completeness - the inverse proportion of missing values
## is_sexless - a boolean representing a traits dependency on sex
perm_df <- missingness %>% 
  transmute(
    source = source,                          # the database citations
    trait = trait,                            # the names of the traits
    completeness = 1 - prop_missing,          # inverse proportion of missingness for each trait
    is_sexless = !(trait %in% sex_dep_vars)   # boolean: FALSE if variable is sex dependent, else TRUE 
  )

# creates a function for the permutation test to see if the improved completeness after removing sex dependent variables is significantly greater than 10,000 random selections of variables
perm_test <- function(df, n = 10000, seed = 1){
  set.seed(seed)
  
  x <- df$completeness                    # completeness of each trait
  sexless <- df$is_sexless                # boolean: FALSE if var is sex dependent
  k <- sum(sexless)                       # number of sex independent variables
  
  mu_all <- mean(x)                       # mean completeness by database of all variables
  mu_no_sex <- mean(x[df$is_sexless])     # mean completeness of only sex-independent variables
  obs <- mu_no_sex - mu_all               # difference between both means
  
  if(k == 0L || k == length(x)) {
    return(tibble(
      mean_completeness = mu_all,
      mean_completeness_no_sex = mu_no_sex,
      obs_diff = NA_real_,
      p_value = NA_real_
    ))
  }
  
  perm_stats <- replicate(n, {
    idx <- sample.int(length(x), k, replace = FALSE)
    mean(x[idx]) - mu_all
  })
  
  p <- mean(perm_stats >= obs)
  
  tibble(
    mean_completeness = mu_all,
    mean_completeness_no_sex = mu_no_sex,
    obs_diff = obs,
    p_value = p
  )
}

perm_res <- perm_df %>% 
  dplyr::group_by(source) %>% 
  group_modify(~ perm_test(.x, n = 10000, seed = 1)) %>% 
  ungroup()

perm_res %>% 
  mutate(
    p_value = signif(p_value, 3),
    obs_diff = round(obs_diff, 3),
    mean_completeness = round(mean_completeness, 3),
    mean_completeness_no_sex = round(mean_completeness_no_sex, 3)
  ) %>% 
  gt() %>% 
  gt::cols_label(
    source = "Database",
    mean_completeness = "All Vars",
    mean_completeness_no_sex = "Sexless Vars",
    obs_diff = "Difference",
    p_value = "p-value"
    ) %>% 
  gt::tab_spanner(
    label = "Mean Completeness",
    columns = c(mean_completeness, mean_completeness_no_sex)
  )
